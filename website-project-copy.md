# FoodieGo CRM Lifecycle Automation with Braze

## Kart açıklaması

Kaggle tabanlı sipariş verisini CRM’e uygun kullanıcı profillerine dönüştürdüm; yeni kullanıcı karşılama ve pasif müşteri geri kazanma senaryoları için Braze üzerinde iki segment ve iki davranış bazlı Canvas yolculuğu tasarladım.

## Öne çıkanlar

- 2 yaşam döngüsü segmenti
- 2 otomatik Canvas yolculuğu
- 81 kullanıcılık Win-Back hedef kitlesi
- 3 günlük davranış değerlendirme penceresi
- Action Paths ile geri dönen / dönmeyen ayrımı

## Teknolojiler

Braze · Python · Pandas · Kaggle · CSV · CRM Automation

## Uyarı

Kişisel demo projesidir. Braze ücretsiz deneme ortamında taslak olarak hazırlanmış, gerçek müşterilere gönderilmemiştir.
